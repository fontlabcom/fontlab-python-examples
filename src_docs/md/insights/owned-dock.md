# Owned metrics dock

Dock/panel composition without host UI mutation.

The retained catalogue records these interaction checks: Toggle, float and redock the panel within its own window; FontLab panels unchanged; named close cleans all.

This is an archived example. Review its imports and host assumptions before running it.
