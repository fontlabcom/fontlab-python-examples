# Python examples for FontLab

These examples show PythonQt patterns used inside FontLab: owned windows,
signals, item models, drawing and small font operations.

This checkout is being reorganized. The previous example catalogue and its
source files are archived externally with historical prefix `rescued/part2`. Their recorded native results
describe those earlier implementations. Building this documentation does not
rerun them or install the previous launcher.

Start with [the example collections](collections.md), then read a complete
[insight example](insights/index.md). For current menu tools, use
[Scriptmix](https://fontlabcom.github.io/fontlab-python-scriptmix/).
For the native APIs, use the
[FontLab Python reference](https://fontlabcom.github.io/fontlab-python-docs/).

[Browse current menu sources](current/index.md). These files and the retained
catalogue have separate identities and acceptance histories. A documentation
build does not rerun or qualify any native example.

Browse the [100 current practical scripts](current/index.md) for current font inspection, proofs, editing, panels and packaged GetGo lessons. Archived dispatchers have been removed
from the active Scripts tree. Their original sources and resources remain in the
external rescue archive; removing a menu does not qualify or complete its workflow.

Explore both [component dependency graph profiles](elastic-component-graphs.md),
with complete original elastic controls and an immutable font snapshot.
