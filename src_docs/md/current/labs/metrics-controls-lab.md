# Metrics Controls Lab

Metrics Controls Lab: explore related PythonQt controls beside a live font preview.

Setup: FontLab 9, Fly, fontlab-python-lessons and the matching App WP09
core PythonQt labs candidate.
Usage: Choose a named profile, inspect its controls and preview, then use the
labelled actions. Refresh captures the current context; Close releases owners.
Credits: FontLab Python examples and App contributors; Apache-2.0.

Run **Labs > Metrics Controls Lab** from FontLab's Scripts menu.

Read [collections](../../collections.md) and [contributing](../../contribute.md) before use.
