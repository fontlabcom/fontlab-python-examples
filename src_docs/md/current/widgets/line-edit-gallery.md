# Line Edit Gallery

Show line edit gallery using FontLab PythonQt; no font data is changed.

Run **Widgets > Line Edit Gallery** from FontLab's Scripts menu.

Read [collections](../../collections.md) and [contributing](../../contribute.md) before use.
