# Easing Curve Gallery

Show easing curve gallery using FontLab PythonQt; no font data is changed.

Run **Graphics > Easing Curve Gallery** from FontLab's Scripts menu.

Read [collections](../../collections.md) and [contributing](../../contribute.md) before use.
