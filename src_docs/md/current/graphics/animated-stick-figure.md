# Animated Stick Figure

Show animated stick figure using FontLab PythonQt; no font data is changed.

Run **Graphics > Animated Stick Figure** from FontLab's Scripts menu.

Read [collections](../../collections.md) and [contributing](../../contribute.md) before use.
